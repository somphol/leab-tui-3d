      Room PIN

      How the PIN works

      A 5-digit PIN is generated for each room. New PIN replaces it for future joins. Guests need the code + PIN, then you approve them.

      The host keeps only a SHA-256 digest in memory. The PIN is not in the invite link, saved game or exported file. Copy invite + PIN is the one-paste share text.
